# Roll a Ball

_Made by Unity 6_

## Basic Game Info
- The player controls a rolling ball to collect objects in the scene.
- The goal is to collect all objects to progress through different areas and complete the game.

## Feature Enhancements
- After collecting all objects in one area, a gate will open to unlock the next area. This divides the game into small levels instead of a single open area.
- Each area in the game has different ground color. The player ball changes color to indicate which area of the game is currently active. This will improve player’s orientation.
- The cyan orbs add a force which will push the player ball away. Player needs to control the ball to avoid these orbs or also can use them to gain a speed boost.
- The north area is completely vertical. When the ball enters this area, game will modify gravity direction to allow player to move along the vertical ground. This adds more movement mode compared to the original tutorial, which will provide player a better experience.
- Some rotating walls are added to make the game more challenges and increasing difficulty. Player needs to move the ball more strategically or anticipate the position of the rotating walls.
